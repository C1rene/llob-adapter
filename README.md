# Yunzai NapCat 适配器 NapCat-Adapter

#### 简介
自用改版

#### 警告

* **重要！** 请勿将 `napcat-adapter（即本项目）` 和 `NapCat.OneBot` 项目以任何形式发布到“bilibili、抖音、快手”等国内媒体平台。

#### 安装方式

**GitHub 源**

```bash
git clone --depth=1 https://github.com/C1rene/llob-adapter.git ./plugins/llob-adapter
```

**安装依赖**

```bash
cd plugins/llob-adapter
pnpm install
```
